# 🛒 SmartList (বাজার তালিকা) — Project Report & Documentation

**SmartList (বাজার তালিকা)** হলো একটি সহজ, দ্রুত এবং আধুনিক অফলাইন-ফার্স্ট কেনাকাটার তালিকা (Bazar / Grocery List) এবং খরচের হিসাব রাখার মোবাইল অ্যাপ্লিকেশন। এটি বিশেষভাবে বাংলাদেশের সাধারণ ব্যবহারকারীদের দৈনন্দিন বাজারের অভিজ্ঞতা সহজ ও সুশৃঙ্খল করার জন্য তৈরি। অ্যাপটি **BDApps** প্ল্যাটফর্মের মাধ্যমে রবি (Robi) ও সার্কেল (Cirkle - সাবেক Airtel) নেটওয়ার্কের সাবস্ক্রিপশন ও ওটিপি (OTP) ভিত্তিক অথেন্টিকেশনের সাথে যুক্ত।

## 📖 প্রজেক্টের বিবরণ (Project Overview)

দৈনন্দিন জীবনে কাঁচাবাজার বা সুপারশপে কেনাকাটার সময় কাগজ-কলমে তালিকা তৈরি করা অথবা ফোনে হিজিবিজি নোট রাখা বেশ ঝামেলার। বাজার করার সময় কোন জিনিসটি কেনা হলো, কোনটি বাকি আছে এবং মোট কত টাকা খরচ হলো—তা তাৎক্ষণিকভাবে হিসাব রাখা অনেকের জন্য কঠিন হয়ে পড়ে।

**SmartList** এই সমস্যাগুলোর সম্পূর্ণ সমাধান প্রদান করে:

- ব্যবহারকারী একাধিক বাজারের তালিকা তৈরি ও সংরক্ষণ করতে পারেন।
- জিনিসপত্রের আনুমানিক বা আসল দাম লিখে মোট খরচের তাৎক্ষণিক হিসাব রাখা যায়।
- কেনা শেষ হলে টিকচিহ্ন দিয়ে আর্কাইভ করে রাখা যায়।
- এক ক্লিকেই সম্পূর্ণ বাজারের ফর্দ পরিবার বা বন্ধুদের কাছে হোয়াটসঅ্যাপ, মেসেঞ্জার বা এসএমএসে শেয়ার করা যায়।

## ✨ মূল ফিচারসমূহ (Key Features)

### ১. একাধিক তালিকা ব্যবস্থাপনা (Multiple Lists Management)

- প্রয়োজন অনুযায়ী একাধিক আলাদা তালিকা তৈরি করা যায় (যেমন: সাপ্তাহিক বাজার, মাসের সদাই, রমজানের বাজার ইত্যাদি)।
- তালিকার নাম এডিট, আর্কাইভ এবং ডিলিট করার সুবিধা।
- ড্রপডাউন থেকে খুব সহজেই এক তালিকা থেকে অন্য তালিকায় সুইচ করা যায়।

### ২. দ্রুত আইটেম যুক্তকরণ ও সম্পাদনা (Quick Add & Item Management)

- দ্রুততম সময়ে আইটেমের নাম, সম্ভাব্য মূল্য এবং ক্যাটাগরি যুক্ত করা।
- কেনা সম্পন্ন হওয়া আইটেমগুলোতে চেকমার্ক (`isBought`) দেওয়া।
- কেনা আইটেম এবং বাকি থাকা আইটেম আলাদাভাবে হাইলাইট হয়।

### ৩. স্বয়ংক্রিয় খরচ ক্যালকুলেশন (Real-time Budget Calculation)

- **মোট আনুমানিক বাজেট (Total Estimated Cost)**: তালিকায় থাকা সব পণ্যের সম্ভাব্য খরচের যোগফল।
- **কেনা বাবদ খরচ (Bought Total)**: যে পণ্যগুলো কেনা হয়েছে সেগুলোর মোট খরচ।
- **বাকি খরচ (Remaining Total)**: যে পণ্যগুলো এখনো কেনা বাকি তার আনুমানিক খরচ।

### ৪. ক্যাটাগরি অনুযায়ী ফিল্টারিং ও কাস্টম ক্যাটাগরি (Categorization)

- ডিফল্ট ক্যাটাগরি: সবজি (Vegetables), মাছ (Fish), মাংস (Meat), মসলা (Spices), অন্যান্য (Others)।
- ব্যবহারকারী চাইলে নিজের পছন্দমতো নতুন ক্যাটাগরি যুক্ত বা কাস্টমাইজ করতে পারেন।
- ক্যাটাগরিভিত্তিক দ্রুত ফিল্টারিংয়ের সুবিধা।

### ৫. সার্চ ও শর্টিং সুবিধা (Search & Sorting)

- **রিয়েল-টাইম সার্চ**: তালিকার যেকোনো পণ্য দ্রুত খুঁজে পেতে তাৎক্ষণিক সার্চ বার।
- **বহুমাত্রিক সর্টিং**:
  - নিজের মতো (Manual drag & drop / custom)
  - আগে যোগ করা (Date Ascending)
  - নতুন যোগ করা (Date Descending)
  - বর্ণানুক্রমিক (A to Z এবং Z to A)

### ৬. তালিকা শেয়ারিং (One-Tap Share)

- তালিকা ও খরচের বিবরণ সুন্দর ফরম্যাটে কপি করে বা সরাসরি WhatsApp, SMS, সোশ্যাল মিডিয়ায় পাঠানোর সুবিধা (`share_plus` প্যাকেজের মাধ্যমে)।

### ৭. আর্কাইভ ও হিস্ট্রি (Archive & History Screen)

- সম্পন্ন হওয়া বাজার তালিকাগুলো আর্কাইভে সংরক্ষণ থাকে।
- পুরনো বাজারের তারিখ ও খরচের হিসাব পরবর্তীতে দেখার সুবিধা।

### ৮. থিম ও বাংলা ফন্ট সাপোর্ট (Theme & Typography)

- ডার্ক মোড (Dark Mode) ও লাইট মোড (Light Mode) টগল অপশন, যা ডিভাইসে স্থায়ীভাবে সেভ থাকে।
- প্রফেশনাল বাংলা টাইপোগ্রাফির জন্য ব্যবহৃত হয়েছে **Tiro Bangla** ফন্ট।

### ৯. বিডিঅ্যাপস সাবস্ক্রিপশন ও অথেন্টিকেশন (BDApps Telco Login)

- রবি (Robi - 018) এবং সার্কেল (Cirkle / সাবেক Airtel - 016) সিম নম্বরের জন্য ডেডিকেটেড লগইন ভ্যালিডেশন।
- ওটিপি (OTP) ভেরিফিকেশন এবং ব্যাকএন্ড এপিআই দিয়ে সাবস্ক্রিপশন স্ট্যাটাস চেক।

## 🗄 ডাটাবেজ আর্কিটেকচার (Database Schema & Migrations)

অ্যাপটিতে লোকাল স্টোরেজ হিসেবে **SQLite** (`sqflite`) ব্যবহার করা হয়েছে। ডাটাবেজের নাম `bazar_talika.db` এবং বর্তমান ভার্সন **৪**।

### টেবিল স্ট্রাকচার:

#### ১. `lists` টেবিল

| ফিল্ড        | ডেটা টাইপ | কনস্ট্রেইন্ট              | বিবরণ                      |
| :----------- | :-------- | :------------------------ | :------------------------- |
| `id`         | INTEGER   | PRIMARY KEY AUTOINCREMENT | তালিকার ইউনিক আইডি         |
| `name`       | TEXT      | NOT NULL                  | তালিকার নাম                |
| `isArchived` | INTEGER   | NOT NULL DEFAULT 0        | আর্কাইভ স্ট্যাটাস (০ বা ১) |
| `createdAt`  | TEXT      | NOT NULL                  | তৈরির সময় (ISO 8601)       |

#### ২. `items` টেবিল

| ফিল্ড               | ডেটা টাইপ | কনস্ট্রেইন্ট              | বিবরণ                    |
| :------------------ | :-------- | :------------------------ | :----------------------- |
| `id`                | INTEGER   | PRIMARY KEY AUTOINCREMENT | পণ্যের ইউনিক আইডি        |
| `listId`            | INTEGER   | FOREIGN KEY (`lists.id`)  | সংশ্লিষ্ট তালিকার আইডি   |
| `name`              | TEXT      | NOT NULL                  | পণ্যের নাম               |
| `price`             | REAL      | NULLABLE                  | পণ্যের দাম               |
| `category`          | TEXT      | NULLABLE                  | ক্যাটাগরি JSON/টেক্সট    |
| `isBought`          | INTEGER   | NOT NULL DEFAULT 0        | কেনা হয়েছে কিনা (০ বা ১) |
| `isArchived`        | INTEGER   | NOT NULL DEFAULT 0        | আর্কাইভ স্ট্যাটাস        |
| `createdAt`         | TEXT      | NOT NULL                  | আপডেটের সময়              |

## 📡 BDApps ও টেলকো সাবস্ক্রিপশন ফ্লো (BDApps & Telco Integration)

অ্যাপটি রবি আজিয়াটা লিমিটেডের **BDApps** এপিআই ভিত্তিক সাবস্ক্রিপশন মডেলে কাজ করে:

- **সাপোর্টেড নেটওয়ার্ক**: রবি (`018...`) এবং সার্কেল (`016...`)।
- **দৈনিক চার্জ**: ২.৭৮ টাকা/দিন (ভ্যাট, এসডি ও এসসি সহ)।
- **এপিআই বেস ইউআরএল**: `https://bdapps.flicksize.com/smartlisting/api/`

### অথেন্টিকেশন ও ওটিপি ফ্লো:

```mermaid
sequenceDiagram
    autonumber
    actor User as ইউজার
    participant App as স্মার্টলিস্ট অ্যাপ
    participant Server as BDApps API সার্ভার

    User->>App: রবি/সার্কেল মোবাইল নম্বর ইনপুট
    App->>Server: POST check_subscription.php
    alt ইতিমধ্যে সাবস্ক্রাইবড (REGISTERED)
        Server-->>App: সাবস্ক্রিপশন সচল
        App->>User: সরাসরি হোম স্ক্রিনে রিডাইরেক্ট
    else নতুন বা আনসাবস্ক্রাইবড ব্যবহারকারী
        App->>Server: POST send_otp.php
        Server-->>User: মোবাইলে ৪-ডিজিটের ওটিপি প্রেরণ
        User->>App: ওটিপি কোড ইনপুট
        App->>Server: POST verify_otp.php
        Server-->>App: ভেরিফিকেশন সাকসেস ও সাবস্ক্রিপশন নিশ্চিত
        App->>User: লগইন সফল এবং হোম স্ক্রিনে প্রবেশ
    end
```

## 🌐 ল্যান্ডিং পেজ (Web Landing Page)

প্রজেক্টের সাথে `frontend/` ফোল্ডারে একটি আধুনিক, রেসপন্সিভ এবং এসইও-বান্ধব ল্যান্ডিং পেজ রয়েছে:

- **টেকনোলজি**: পিওর HTML5, আধুনিক CSS3 ভ্যারিয়েবল ও ভ্যানিলা জাভাস্ক্রিপ্ট (কোনো এক্সটারনাল ডিপেনডেন্সি ছাড়া দ্রুত লোড হয়)।
- **ফিচারসমূহ**:
  - বাংলা ও ইংরেজি দ্বিভাষিক টগল (Language Switcher: BN ⇄ EN)।
  - লাইট ও ডার্ক থিম মোড সুইচ।
  - অ্যাপের সরাসরি APK ডাউনলোড লিংক (`smartlist.apk`)।
  - মোবাইল ও ডেস্কটপ উভয়ের জন্য শতভাগ রেসপন্সিভ লেআউট।
